# 🎵 EchoStream – Simple & Sleek Audio Player

---

## 🚀 Overview
**EchoStream** is a lightweight and user-friendly **web-based audio player** that allows users to **upload, play, pause, and replay audio files**.  
With a clean interface and smooth controls, it is perfect for anyone who wants a **simple audio playback tool** directly in the browser.

---

## ⭐ Features
- 🎧 **Upload Audio** – Select and load any audio file from your device  
- ▶️ **Play / Pause / Replay** – Full control over audio playback  
- 🔁 **Replay Function** – Quickly restart audio from the beginning  
- 📢 **Live Status Updates** – Displays real-time audio status (e.g., *Playing*, *Paused*, *Ended*)  
- 💡 **Simple UI** – Clean, responsive, and centered layout using Flexbox  

---

## 🧰 Technologies Used
- **HTML** – Base structure of the application  
- **CSS** – Styling and layout design  
- **JavaScript** – Audio control logic and file handling  
- **Flexbox** – For clean and centered layout alignment

## 🚀 How to Use
1. Open **index.html** in your browser  
2. Click **"Upload The Audio"** to select an audio file from your device  
3. Use the **Play**, **Pause**, and **Replay** buttons to control playback  
4. View the **audio status** displayed on the screen
